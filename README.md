# Desafio Técnico - QA Automation (Accenture)

Repositório estruturado para a entrega do desafio técnico de automação de testes (API e Frontend) utilizando **Cypress** e **JavaScript**, conforme as diretrizes da Accenture.

## 🚀 Tecnologias Utilizadas
- **JavaScript**
- **Cypress**

## 📁 Estrutura do Projeto
- **Parte 1 (API):** Contém o fluxo automatizado de ponta a ponta da API da DemoQA (Criação de usuário, Geração de Token, Autorização, Listagem de livros, Aluguel de livros e Validação dos detalhes do usuário).
- **Parte 2 (Frontend / UI):** Contém os testes visuais e de formulários (Practice Form com preenchimento de dados, upload do arquivo `.txt` e validação do modal de sucesso).
- **Fixtures:** Contém a massa de dados e o arquivo `.txt` obrigatório para o upload.

## ⚙️ Como Executar
1. Clone o repositório:
   `git clone https://github.com/endersoncastrof-gif/accenture-qa-automation.git`
2. Instale as dependências:
   `npm install`
3. Abra a interface do Cypress:
   `npx cypress open`
